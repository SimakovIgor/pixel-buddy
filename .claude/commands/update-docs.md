# Обновить документацию

Запускать после любой правки, которую видит пользователь: новое поведение, кнопка, команда, вид, трофей, клиент.
Цель: человек за минуту понимает, что это и как поставить, а подробности находит в README плагина. Красиво,
но без перегруза.

## Где живут доки и что в каждой

| Файл | Для кого | Что там |
|---|---|---|
| `README.md` | тот, кто зашел на GitHub | что это одной фразой, установка, «быстрый взгляд» картинками, ссылки дальше. Каждая новая фича максимум строкой или двумя и картинкой, если она есть |
| `pixel-buddy/README.md` | тот, кто уже поставил | все по разделам: виды, еда, настроение, гнездо, трофеи, клики, меню, команды, что мод читает и шлет, хуки, файлы, неполадки |
| `TROPHIES.md`, `TROPHIES.ru.md` | охотники за трофеями | все 14 с условиями, секретные под спойлером. Условия брать из `hooks/trophies.ts`, не по памяти |
| `help` и `HELP_RU` в `hooks/register.tsx` | `/buddy help` | клики, кнопки редактора, еда, рост, трофеи. Короче README |
| заметки к выпуску | GitHub Releases | 2-5 пунктов «что нового» жирным началом, строка про обновление |

## Правила текста

- английский в README и выпусках, русский только в `TROPHIES.ru.md` и `HELP_RU`
- простые короткие фразы, без маркетинга и восклицаний. Не «amazing», а что именно происходит
- без длинного и среднего тире, без точек в конце пунктов списка
- одна фича описывается в одном месте подробно, в остальных одной строкой со ссылкой
- числа и условия сверять с кодом: дни роста (`BABY_DAYS`, `YOUNG_DAYS`), шансы редкости, константы трофеев
- одинаково для всех клиентов: если в терминале клик, то в VS Code и Cursor кнопка, писать оба способа рядом

## Картинки

- перерисовывать каждую картинку, где видно изменившееся: `scratchpad/gifs/compose.mjs <копия hooks> <сцена> <out.json>`,
  потом `render_hq.py <json> <gif|png>`. Копия hooks: `audit/src`, импорты переписать на `.ts` (`[a-z0-9-]+`)
- `docs/vscode.gif` снимается с живого VS Code (`screencapture -v`, кадры через AVFoundation), без чужой переписки в кадре,
  язык питомца английский
- размер и стиль как у соседних картинок, alt-текст описывает, что происходит на картинке
- не больше одной новой картинки на фичу

## Проверка перед коммитом

- все ссылки на картинки и файлы открываются (`curl -sI` по raw-ссылкам после пуша)
- `sh tests/run.sh`, проверка типов и `claude plugin validate --strict pixel-buddy`, если трогалась справка в моде
- перечитать главный README сверху вниз: не стал ли длиннее, чем нужно, нет ли повторов
